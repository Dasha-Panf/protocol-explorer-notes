PROTOCOL EXPLORER — ОПИСАНИЕ ИНТЕРФЕЙСА
Источник: https://protocol-explorer-alpha.vercel.app/
Дата фиксации: 26.11.2026

1. Назначение
Сайт позиционируется как интерактивный учебный ресурс «Learn how the internet works». Его центральный объект — каталог сетевых протоколов с пошаговыми сценариями, которые показывают обмен сообщениями между участниками.

2. Элементы интерфейса, видимые в текстовой версии
- Now learning: текущая тема, в снимке страницы — HTTP · Web Communication.
- Overview: число шагов активного сценария (в снимке — 5).
- OSI Layer: отображается уровень OSI; показана шкала уровней 1–7.
- Search protocols: поиск протоколов, подсказка Ctrl+K.
- Learning progress: индикатор завершения; в снимке — 0%, 0/39 complete, 0 in progress.
- Категории: All 39, Core 11, Application 19, Security 9.
- Internet Protocols: список карточек протоколов и последовательностей их шагов.
- Protocol Overview: подробное описание активного протокола и его характеристик.
- Packet trace: таблица с номером пакета, временем, источником, назначением, протоколом, информацией и размером.

3. Значение интерактивного подхода
Сценарий показывает не только конечный результат, но и порядок зависимых операций. Например, перед HTTP-запросом браузеру требуется разрешить доменное имя в IP-адрес; для TCP-соединения выполняется handshake; затем отправляется запрос и приходит ответ.

4. Границы доступного снимка
Статический текстовый снимок поискового индекса даёт название всех карточек и краткие этапы. 
5. Как использовать конспект
Начинать с сетевых основ, затем изучать базовые протоколы, после этого — прикладные сценарии, безопасность и анализ трассировок. Сопоставлять шаги карточки с фактическими полями пакетов.
