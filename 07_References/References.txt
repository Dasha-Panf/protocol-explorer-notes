СТАНДАРТЫ И ИСТОЧНИКИ

Первичный учебный источник:
https://protocol-explorer-alpha.vercel.app/

Стандарты, упомянутые в доступной карточке HTTP:
- RFC 9110 — HTTP Semantics.
- RFC 9112 — HTTP/1.1.

Для углублённой проверки конкретных протоколов следует сверяться с действующими RFC и спецификациями соответствующих организаций. Не следует считать, что список RFC для HTTP применим к другим карточкам.

Полезные каталоги:
- RFC Editor: https://www.rfc-editor.org/
- IETF Datatracker: https://datatracker.ietf.org/
- IEEE Standards Association: https://standards.ieee.org/
- Wi-Fi Alliance: https://www.wi-fi.org/

Принцип документирования:
1. Сначала фиксировать то, что явно отображено на сайте.
2. Затем сверять нормативные детали по официальной спецификации.
3. Датировать проверку меняющихся технических сведений.
4. Не приписывать учебному сценарию точность реального packet capture.
