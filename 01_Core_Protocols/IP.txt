IP — INTERNET PROTOCOL
Источник: Protocol Explorer, карточка IP.

ПО САЙТУ
Сценарий:
1. Local or not? — сравнение адреса назначения с подсетью.
2. Find the router — ARP преобразует IPv4-адрес в MAC-адрес.
3. Send the packet — адреса, TTL и поле Protocol.
4. NAT, then hop by hop — маршрутизатор выполняет преобразование и пересылает пакет.
5. The reply comes back — NAT выполняет обратное преобразование для ноутбука.

ПОЯСНЕНИЕ
IP обеспечивает логическую адресацию и маршрутизацию пакетов между сетями. Он не гарантирует доставку, порядок или отсутствие дубликатов.
IPv4-заголовок содержит адреса источника и назначения, TTL, поле Protocol, длину и другие поля. TTL уменьшается на каждом маршрутизаторе; при достижении нуля пакет отбрасывается, обычно с ICMP Time Exceeded.
Если адрес назначения находится в той же подсети, узел пытается доставить кадр напрямую. Если адрес удалённый, кадр передаётся MAC-адресу шлюза по умолчанию. ARP используется в IPv4 для поиска MAC следующего узла в локальном сегменте.
NAT изменяет адресную информацию, часто вместе с портами (PAT/NAPT), чтобы сопоставлять частные адреса с внешним адресом.

СВЯЗАННЫЕ ТЕМЫ
IPv6, Ethernet, ARP, ICMP, NAT, TCP, UDP.
