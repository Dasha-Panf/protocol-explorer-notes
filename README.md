# Protocol Explorer — structured study notes

Подробная база знаний по интерактивному каталогу [Protocol Explorer](https://protocol-explorer-alpha.vercel.app/). В доступном представлении сайта показаны счётчики: All (39), Core (11), Application (19), Security (9).

## Навигация по репозиторию

| Папка | Содержание |
|---|---|
| `00_About/` | Описание сайта и карта его каталога |
| `01_Core_Protocols/` | Основные протоколы обмена и транспортного уровня |
| `02_Application_Protocols/` | Прикладные и сетевые протоколы |
| `03_Security_Protocols/` | Протоколы и технологии безопасности |
| `04_Network_Fundamentals/` | OSI, инкапсуляция, IP-адресация и порты |
| `05_Packet_Analysis/` | Объяснение packet trace и пример HTTP-трассировки |
| `06_Glossary/` | Словарь терминов и сокращений |
| `07_References/` | Первичный сайт и нормативные источники |

## Каталог протоколов

В папках размещены отдельные документы по всем 39 карточкам, которые перечислены в текстовом представлении сайта. Счётчики групп, показанные интерфейсом, — Core 11, Application 19 и Security 9. Распределение файлов по папкам в этом репозитории — редакционная классификация для удобства изучения; она не выдаётся за подтверждённую внутреннюю логику фильтров приложения.

Полный список с названиями карточек и путями к документам находится в `00_About/02_Catalog_Map.txt`.

## Формат отдельных файлов

Файлы протоколов в формате `.txt` включают:
- сценарий и названия шагов так, как они отображаются на сайте;
- назначение и принцип работы;
- уровни, транспорт, порты и стандарты — там, где данные подтверждены;
- пояснение терминов и последовательности обмена;
- ограничения и вопросы безопасности;
- связи с другими протоколами.

Маркировка «СЦЕНАРИЙ САЙТА» фиксирует содержание карточки. Раздел «ПРИНЦИП РАБОТЫ» или «ПОЯСНЕНИЕ» содержит дополнительное объяснение для понимания, а не цитату сайта.

## Важное замечание о полноте источника

Сайт интерактивный. По доступной текстовой версии удалось сверить заголовок, счётчики групп, все 39 названий и краткие последовательности шагов. Для HTTP дополнительно доступен полный Overview и пример packet trace (DNS → TCP handshake → HTTP GET → 200 OK). Динамические подробные панели остальных карточек и их полные packet trace не были целиком доступны в текстовом представлении. Поэтому отсутствующие значения не выдумываются; поясняющий материал отделён от данных карточки.

## Порядок изучения

Начни с `04_Network_Fundamentals/Network_Basics.txt`, затем пройди Core, Application и Security. После этого открой `05_Packet_Analysis/Reading_Packet_Trace.txt` и попробуй сопоставить каждый шаг карточки с источником, назначением, протоколом и размером строки в трассировке.
