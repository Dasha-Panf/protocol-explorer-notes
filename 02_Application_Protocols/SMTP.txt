SMTP — SIMPLE MAIL TRANSFER PROTOCOL
Источник: Protocol Explorer, карточка SMTP.

СЦЕНАРИЙ САЙТА
1. CONNECT SECURELY — порт 465, TLS с самого начала.
2. GREETING & LOGIN — EHLO, затем AUTH.
3. SEND THE MESSAGE — envelope, затем содержимое.
4. FIND BOB’S SERVER — MX-запрос через DNS.
5. SERVER TO SERVER — порт 25, STARTTLS.
6. DELIVER — транзакция повторяется для доставки на сервер получателя.

ПРИНЦИП РАБОТЫ
SMTP используется для отправки электронной почты и передачи писем между почтовыми серверами. EHLO сообщает серверу о возможностях клиента и поддерживаемых расширениях. Envelope-команды MAIL FROM и RCPT TO задают отправителя и получателей на уровне SMTP; команда DATA начинает передачу заголовков и тела письма.
DNS MX-запись указывает серверы, принимающие почту для домена-получателя.
Порты:
- 25 — преимущественно передача почты между серверами.
- 587 — message submission, часто с STARTTLS.
- 465 — submission поверх implicit TLS.
Карточка сайта показывает клиентское соединение по 465 и передачу между серверами по 25 с STARTTLS. Это типовой учебный вариант; точная конфигурация зависит от провайдера и политики серверов.
STARTTLS пытается переключить уже установленное соединение на TLS. Если TLS не обязателен и downgrade не защищён политикой, возможны риски. TLS на транспортном участке не означает сквозное шифрование письма от автора до адресата.
