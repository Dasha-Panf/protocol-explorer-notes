MODBUS — INDUSTRIAL CONTROL (OT)
Источник: Protocol Explorer, карточка Modbus.

СЦЕНАРИЙ САЙТА
1. PORT 502 — TCP-соединение к PLC.
2. READ REGISTERS — Function 3 читает четыре значения.
3. WRITE A SETPOINT — Function 6 записывает один регистр.
4. START A PUMP — Function 5 управляет coil.
5. AN EXCEPTION — ответ об ошибке при обращении к несуществующему регистру.
6. NO SECURITY — предупреждение: доступ может получить тот, кто способен достичь устройства.

ПРИНЦИП РАБОТЫ
Modbus — промышленный протокол обмена данными и командами между PLC, датчиками, исполнительными устройствами и системами диспетчерского управления.
В Modbus TCP сообщения передаются по TCP; типичный порт — 502.
Function Code 03 — чтение Holding Registers.
Function Code 06 — запись одного Holding Register.
Function Code 05 — управление одним Coil.
Ответ может быть обычным или exception response, если сервер не может выполнить запрос.
Регистры и coils — адресуемые области данных устройства; их значение и допустимый диапазон зависят от конкретного контроллера и документации производителя.

БЕЗОПАСНОСТЬ OT
Базовый Modbus TCP не обеспечивает встроенную современную аутентификацию и шифрование. Доступ должен ограничиваться промышленным сегментом, firewall и контролируемыми шлюзами. Любые тесты команд записи на реальном PLC допустимы только с разрешением владельца оборудования и утверждённой процедурой.

СВЯЗИ
TCP, PLC, SCADA, OT security, Holding Registers, Coils.
