DHCP — DYNAMIC HOST CONFIGURATION PROTOCOL
Источник: Protocol Explorer, карточка DHCP.

ПО САЙТУ
Сценарий:
1. No address yet — устройство подключается к сети без настроенного адреса.
2. Discover — широковещательный поиск сервера.
3. Offer — маршрутизатор предлагает адрес.
4. Request — клиент публично запрашивает предложенный адрес.
5. Acknowledge — сервер подтверждает аренду.
6. Renew — обновление аренды примерно на середине срока в сценарии.

ПОЯСНЕНИЕ
DHCPv4 автоматически выдаёт параметры сети: IPv4-адрес, маску, шлюз, DNS-серверы, срок аренды и дополнительные опции.
Классическая последовательность DORA: Discover, Offer, Request, Acknowledge. Начальный обмен часто использует UDP-порты 68 (клиент) и 67 (сервер). Клиент без адреса может использовать широковещательные пакеты.
Аренда ограничена временем. Клиент пытается продлить её до истечения срока. DHCP не является протоколом маршрутизации и сам не передаёт пользовательский трафик.

СВЯЗАННЫЕ ТЕМЫ
IPv4, DNS, IPv6, UDP, шлюз по умолчанию.
