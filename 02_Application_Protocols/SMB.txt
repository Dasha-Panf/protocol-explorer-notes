SMB — SERVER MESSAGE BLOCK
Источник: Protocol Explorer, карточка SMB.

СЦЕНАРИЙ САЙТА
1. PORT 445 — TCP-соединение к NAS.
2. NEGOTIATE — согласование версии SMB.
3. NTLM CHALLENGE — NAS отправляет случайное значение.
4. NTLM RESPONSE — клиент отправляет доказательство, а не пароль.
5. CONNECT A SHARE — пример \nas\Documents.
6. OPEN THE FILE — команда CREATE.
7. READ IT — чтение файла.
8. CLOSE THE FILE — закрытие; сайт советует держать порт 445 внутри домашней сети.

ПРИНЦИП РАБОТЫ
SMB обеспечивает доступ к общим файлам, папкам, принтерам и другим ресурсам. Клиент устанавливает TCP-соединение, согласует диалект SMB, проходит аутентификацию, подключается к share (tree connect), открывает файл, выполняет операции чтения/записи и закрывает его.
TCP 445 — типичный порт SMB direct hosting.
NTLM challenge-response не пересылает пароль в открытом виде, но сам NTLM имеет ограничения и не равен современной безусловно надёжной аутентификации. В доменной среде обычно предпочитается Kerberos, когда он доступен.
SMB signing помогает защищать целостность обмена; SMB encryption может шифровать трафик SMB при поддержке и включении функции.

БЕЗОПАСНОСТЬ
Не выставлять TCP 445 напрямую в публичный Интернет. Использовать сегментацию, firewall, обновления, сильную аутентификацию и ограничение доступа по принципу минимальных привилегий.

СВЯЗИ
TCP, NAS, Windows file sharing, NTLM, Kerberos.
