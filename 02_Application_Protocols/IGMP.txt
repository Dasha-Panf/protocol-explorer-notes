IGMP — INTERNET GROUP MANAGEMENT PROTOCOL
Источник: Protocol Explorer, карточка IGMP.

ПО САЙТУ
Сценарий:
1. Pick a channel — телевизионная приставка вступает в multicast-группу.
2. Ask the provider — маршрутизатор присоединяется к группе от имени домашней сети.
3. The channel flows — поток идёт только туда, где его запросили.
4. A second screen — ноутбук также подключается к группе.
5. Still watching? — маршрутизатор периодически проверяет участие.
6. Leave — ноутбук покидает группу.

ПОЯСНЕНИЕ
IGMP используется в IPv4-сетях для управления членством узлов в multicast-группах. Он помогает маршрутизаторам понять, какие сегменты сети заинтересованы в получении multicast-потока. Сам IGMP не маршрутизирует multicast-трафик между всеми сетями — для этого используются механизмы multicast routing.
В IPv6 аналогичную функцию управления членством выполняет MLD (Multicast Listener Discovery), основанный на ICMPv6.

СВЯЗАННЫЕ ТЕМЫ
IP multicast, Ethernet multicast, IPTV, MLD.
