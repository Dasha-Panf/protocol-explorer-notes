IMAP — INTERNET MESSAGE ACCESS PROTOCOL
Источник: Protocol Explorer, карточка IMAP.

СЦЕНАРИЙ САЙТА
1. CONNECT SECURELY — порт 993, TLS с самого начала.
2. LOG IN — команды содержат теги.
3. OPEN THE INBOX — SELECT выбирает папку.
4. READ A MESSAGE — FETCH и флаг \Seen.
5. WAIT FOR NEW MAIL — IDLE позволяет серверу отправлять уведомления.

ПРИНЦИП РАБОТЫ
IMAP предоставляет клиенту доступ к почтовым сообщениям и папкам, которые обычно хранятся на сервере. Благодаря этому несколько устройств могут видеть синхронизированное состояние почтового ящика.
Каждая команда IMAP имеет тег, чтобы клиент мог сопоставить ответ с запросом. SELECT выбирает mailbox. FETCH получает атрибуты или содержимое сообщения. Флаг \Seen указывает, что сообщение отмечено прочитанным. IDLE позволяет серверу уведомлять клиента об изменениях без постоянного опроса.
993 — IMAP поверх implicit TLS (IMAPS). Обычный IMAP может использовать порт 143 и команду STARTTLS, если сервер её поддерживает.
IMAP удобен для синхронизации папок, флагов и писем между несколькими устройствами.

СВЯЗИ
SMTP, POP3, TLS, почтовая инфраструктура.
