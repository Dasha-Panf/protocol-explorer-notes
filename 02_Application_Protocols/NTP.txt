NTP — NETWORK TIME PROTOCOL
Источник: Protocol Explorer, карточка NTP.

СЦЕНАРИЙ САЙТА
1. CLOCKS DRIFT — часы ноутбука немного отстают.
2. ASK FOR THE TIME — T1: момент отправки запроса.
3. THE ANSWER — T2 и T3 на сервере, T4 при получении.
4. THE OFFSET — четыре отметки времени дают две оценки.
5. EASE IT IN — время корректируется плавно, без скачка назад.

ПРИНЦИП РАБОТЫ
NTP синхронизирует часы устройств в сети. В типичном запросе клиент фиксирует T1 (отправка), сервер — T2 (получение) и T3 (отправка ответа), клиент — T4 (получение ответа).
Приближённая оценка смещения часов:
offset = ((T2 − T1) + (T3 − T4)) / 2.
Приближённая оценка круговой задержки:
delay = (T4 − T1) − (T3 − T2).
Точность зависит от задержки, асимметрии маршрута, качества часов и сети. NTP обычно использует UDP порт 123.
Для корректировки времени ОС может постепенно менять скорость хода часов (slewing), а не резко переводить время назад, чтобы не нарушать работу приложений и журналов.

СВЯЗИ
UDP, системные часы, временные метки, TLS-сертификаты, синхронизация журналов.
