ETHERNET — FRAMES AND SWITCHES
Источник: Protocol Explorer, карточка Ethernet.

СЦЕНАРИЙ САЙТА
1. WHO HAS THE NAS? — широковещательный запрос MAC-адреса.
2. LEARN, THEN FLOOD — коммутатор запоминает порт ноутбука.
3. ONLY THE NAS ANSWERS — ответ направляется на один порт.
4. PORT TO PORT — кадры идут только туда, куда требуется.
5. OFF THE NETWORK — кадр для маршрутизатора.
6. A NEW FRAME — на каждом hop пакет получает новую канальную оболочку.

ПРИНЦИП РАБОТЫ
Ethernet — семейство технологий канального уровня. Ethernet-кадр обычно содержит MAC-адрес назначения, MAC-адрес источника, поле Type/Length, полезную нагрузку и FCS (Frame Check Sequence) для обнаружения ошибок.
Коммутатор изучает MAC-адрес источника входящего кадра и связывает его с входным портом. Если MAC назначения известен, кадр направляется на соответствующий порт. Если адрес неизвестен, switch может разослать кадр по портам VLAN, кроме входного. Broadcast рассылается в пределах широковещательного домена.
При переходе через маршрутизатор IP-пакет помещается в новый кадр для следующего канального сегмента. MAC-адреса меняются на каждом L2 hop, IP-адреса обычно сохраняются (за исключением NAT и других преобразований).

СВЯЗИ
IP, ARP, IPv6 Neighbor Discovery, VLAN, коммутаторы и маршрутизаторы.
